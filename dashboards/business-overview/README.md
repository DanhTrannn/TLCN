# Business Overview Dashboard

Dashboard Superset gồm năm khu vực:

1. Sales overview.
2. Funnel overview.
3. Product performance.
4. Inventory status.
5. Repurchase propensity.

Chỉ export dataset/chart/dashboard YAML hoặc ZIP đã loại secret vào thư mục này. Dashboard không kết nối trực tiếp MySQL ecommerce hoặc Delta Gold.
